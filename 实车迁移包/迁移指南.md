sudo apt install python3-colcon-common-extensions ros-humble-navigation2 ros-humble-nav2-bringup \

## 3. 你必须动手改的 TODO 清单（按顺序；细节与验收数值都在 计划.md 对应节）

### ① 车端 ROS1 驱动验收（不是填 launch——驱动就在车端跑，PC 侧永远不碰）
按 计划.md §1.5 在车端起 `roslaunch` 三条（底盘+雷达+相机）并 `rostopic hz` 验收四话题；
再按 §1.4 起 PC 桥、PC 端 `ros2 topic hz` 复验。
**验收**：PC 端 /scan ≥5 Hz、/image_raw/compressed ≥10 Hz、发 /cmd_vel 车轮转。

### ② real_robot.urdf.xacro —— 卷尺实测三个 joint origin
量激光雷达/相机/IMU 相对 base_link（两轮轴线中点贴地）的 x/y/z 与朝向角，
替换文件里三处 `TODO`（当前是仿真值占位）。
**验收**：`ros2 run tf2_ros tf2_echo base_link laser_link` 输出与卷尺一致；RViz 里激光点贴直墙成直线。

### ③ 里程计标定（OriginBot 系数法，计划.md §2.1）
线速度/角速度各做 3–5 次取平均系数，写进**车端** `originbot_base/launch/robot.launch.py`
（ROS1 直接改安装空间 launch 参数，不用编译）。
**验收**：走 2 m 误差 <2%，转 360° 误差 <2%，推正方形回来偏差 <5 cm/3°。

### ④ 建图 + 实车地图（全在 PC 端）
```bash
# 前置：启动三件套 ①②（车端驱动 + PC 桥，计划.md 开头总览表）
# 【PC 端】
mkdir -p ~/maps
ros2 launch smart_community_bringup competition_real.launch.py use_navigation:=false use_slam:=true
# RViz2 看图 + teleop 遥控慢速绕场两圈（走闭环），然后另开终端存图：
ros2 run nav2_map_server map_saver_cli -f ~/maps/community_real --occ 0.65 --free 0.25 -t 2000
```
✅ 应看到：`ls ~/maps/` 出 `community_real.pgm` + `community_real.yaml` 两个文件。

### ⑤ nav2_params_no_keepout.yaml —— 三处实车值
- `amcl.initial_pose`：换成实车出发区的 x/y/yaw（现在是仿真起点）
- `robot_radius` / `footprint`：实测车身含外沿的长宽，方法见计划.md §5.1
- 速度限幅：`max_vel_x` 先 0.15–0.25，丝滑了再加

### ⑥ waypoints_cruise.yaml —— 航点全部重标（仿真坐标作废）
逐点标定法（计划.md §5.3 有完整版）：
```bash
# 【PC 端】开一个终端实时读位姿：
ros2 topic echo /amcl_pose
# 遥控车到目标点摆正 → 读 x,y 与 yaw（四元数转法见计划.md §7）→ 记录 → 下一点
# 全部标完写进 waypoints_cruise.yaml（格式不变，只改数值）
# 四元数转 yaw：
python3 -c "import math;z=Z;w=W;y=math.degrees(2*math.atan2(z,w));print(y if y<=180 else y-360)"
```
> 注意 `colcon build --symlink-install` 下 config 是链接，直接改 `src/.../config/` 里的文件即可生效（改完重启节点）。
> 每个点验收：echo 出的位姿与目标差 <5 cm / 5°。

## 4. 阶段化跑法（competition_real.launch.py 的四个档位；每次都先起三件套 ①②）

```bash
# 阶段①：只起 URDF+odom TF，看桥来话题与 TF（车端驱动已自起）
ros2 launch smart_community_bringup competition_real.launch.py use_navigation:=false

# 阶段②：加 Nav2，RViz 里 2D Goal Pose 手动点单点试走（先 2D Pose Estimate 设初始位姿）
ros2 launch smart_community_bringup competition_real.launch.py

# 阶段③：纯巡航丝滑测试（★先跑这个，不加识别！所有点 task=turn）
ros2 launch smart_community_bringup competition_real.launch.py start_mission:=true \
    map:=~/maps/community_real.yaml
# 验收：每点停住、朝向 <5°、不撞不压、单圈计时。连续 10 轮。
# 不丝滑 → 调参顺序：降 max_vel_x/acc_lim_x → 急弯加 turn 辅助点 → 调 DWA critic 权重

# 阶段④：全任务（识别开启；weights 是 PC 本地路径，~ 可用）
ros2 launch smart_community_bringup competition_real.launch.py start_mission:=true \
    use_perception:=true people_weights:=~/weights/people_best.pt \
    map:=~/maps/community_real.yaml \
    people_hfov:=<§2.3实测弧度> people_landmarks:=<§5.3重测yaml绝对路径> \
    waypoints:=<任务版waypoints绝对路径>
# （此时 waypoints 换回任务版——同样要按实车地图重标后用）
```

比赛当天的一键启动 = 三件套 ①② + 阶段④ 命令写成两个脚本（车端一个、PC 一个），打印成赛台启动卡。

## 6. 常见坑（速查）

| 症状 | 原因/解法 |
|---|---|
| PC 桥看不到车端话题 | 车端没设 `ROS_IP`（每个新 shell 都要 export，计划.md §1.3）/ 车端 master 没起 / 不同网段 |
| 桥起了但 ros2 topic hz 为 0 | WiFi 带宽不够或桥白名单少了该话题（白名单只有 4 个，计划.md §1.4） |
| map_server 起不来 | `map:=` 路径不对或地图没存（应存 `~/maps/`，不是车端路径） |
| 编译报找不到 gazebo | 你拿错包了，实车包已删 gazebo，用 `实车迁移包/` |
| AMCL 一启动就飘 | 里程计没标定（回 ③）或 URDF 雷达 TF 错（回 ②） |
| 建图重影 | 里程计标定差 / 遥控太快（0.15 m/s 以内） |
| 到点朝向总差几度 | `yaw_goal_tolerance` 别小于 0.09；观察点 yaw 重标 |
| 车在直角弯卡住 | footprint 太大或该处加 turn 辅助点 |
| 非交互 ssh 跑 ros2 报 command not found | 脚本里自己 `source /opt/ros/humble/setup.bash && source ~/smart_community_ws/install/setup.bash`（ssh 不加载 .bashrc） |
